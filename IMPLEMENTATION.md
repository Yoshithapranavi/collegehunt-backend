### ✅ Decision Score Engine + Shortlist API
- [x] POST /score endpoint with weighted scoring
- [x] Dimension scores: placement (0-100), fees (0-100, inverted), location (tier-based)
- [x] Normalized weights (sum = 1.0)
- [x] Deterministic scoring (same weights → same order)
- [x] POST /shortlist to save college selections per session
- [x] GET /shortlist/:session_id to retrieve saved shortlists
- [x] Session-based (no auth needed, uses header token)
- [x] GET /colleges/:id/predictor for admission probability

**Scoring Algorithm:**
```
placement_score = (avg_package / 40) * 100  [0-100]
fees_score = ((max_fee - min_fee) / (max_fee - min_fee_expected)) * 100  [0-100, inverted]
location_score = tier_based(city)  [85 for Tier-1, 70 for Tier-2, 55 for Others]
overall_score = placement * w1 + fees * w2 + location * w3
```

**Unit Tests (3 edge cases):**
1. ✅ Equal weights (each 33.3%)
2. ✅ Single weight 100% (placement only)
3. ✅ Extreme fee range (expensive college)

## 🚀 API Endpoints Summary

### College Data
- `GET /api/colleges` - List with filters + search
- `GET /api/colleges/:id` - College details
- `POST /api/colleges/compare` - Compare 2+ colleges
- `GET /api/colleges/:id/predictor` - Admission probability

### Scoring
- `POST /api/score` - Calculate weighted scores
- `POST /api/score/shortlist` - Save shortlist
- `GET /api/score/shortlist/:session_id` - Get shortlist

### Reviews (Public)
- `POST /api/reviews/:id/create` - Submit review
- `GET /api/reviews/:id` - Get approved reviews

### Admin (API Key Protected)
- `POST /api/admin/reviews/:id/approve` - Approve review
- `POST /api/admin/reviews/:id/reject` - Reject review
- `GET /api/admin/reviews/pending` - List pending
- `GET /api/admin/stats` - Dashboard stats

### Utility
- `GET /health` - Health check
